# 灵感记录卡 · Inspire Cards

> 一款纯前端、零依赖、本地存储的黑客风格灵感记录工具。
> 黑底 + 绿色数据流，双击即用，你的想法只属于你自己。

版本：v1.0  
更新日期：2026-08-16

---

## 项目简介

一款轻量级的本地灵感记录工具，以「黑底 + 黑客数据流」为视觉基调，支持灵感的增删改查、标签化管理、多主题切换、卡片动画展示、本地导入导出等功能。纯前端实现，**无需后端、无需构建工具**，双击 `index.html` 即可运行。所有数据保存在浏览器 `localStorage` 中，不上传任何服务器。

---

## 特性亮点

- **纯前端零依赖**：原生 HTML + CSS + JavaScript，无框架、无构建，双击即跑
- **本地存储**：数据完全保存在浏览器中，不上传任何服务器
- **黑客数据流背景**：经典 Matrix 数字雨，4 套主题色配色一键切换
- **瀑布流卡片布局**：响应式 4/3/2/1 列自适应，支持手动切换列数
- **浮动 / 滚动双模式**：卡片少时缓慢浮动，卡片多时纵向循环滚动（可暂停）
- **标签化管理 + 搜索**：自由标签、标签云筛选、关键词实时搜索
- **多主题 / 多字体**：4 套数据流主题 + 4 种字体预设，即时切换并持久化
- **本地导入 / 导出**：JSON 格式备份，支持覆盖 / 合并两种导入模式
- **首次启动引导**：5 步蒙层式功能引导，可随时重新查看
- **可读性保障**：数字雨不干扰阅读，对比度满足 WCAG AA 标准

## 快速开始

1. 克隆仓库：

   ```bash
   git clone git@github.com:sharpsilver0222-web/cards.git
   cd cards
   ```

2. 直接用浏览器打开 `index.html` 即可运行。

   或者启动一个本地静态服务器（推荐，避免某些浏览器对 `file://` 的限制）：

   ```powershell
   # PowerShell
   python -m http.server 8000
   # 然后访问 http://127.0.0.1:8000/
   ```

3. 首次打开会弹出 5 步功能引导，跟随引导体验即可。

> 附带两个测试页面，便于快速体验两种展示模式：
> - `test1.html`：预置 2 张卡片，演示**浮动模式**
> - `test2.html`：预置 16 张卡片，演示**滚动模式**

## 功能详解

### 灵感卡片操作

| 功能 | 说明 |
|------|------|
| 新增灵感 | 点击「+ 新建」按钮，弹出编辑弹窗，填写后保存即生成卡片 |
| 查看灵感 | 点击卡片弹出查看弹窗，底部可进入编辑 |
| 编辑灵感 | 在查看弹窗中点击「编辑」，修改内容后保存，更新修改时间 |
| 删除灵感 | 编辑弹窗中「删除」按钮，二次确认后删除 |
| 搜索灵感 | 顶部搜索框，输入关键词实时过滤标题、内容、标签 |
| 标签筛选 | 点击标签云或卡片上的标签，仅展示含该标签的卡片；再次点击取消 |
| 排序切换 | 按修改时间 / 创建时间 升降序，共 4 种排序方式 |

### 标签系统

- 每条灵感可挂 0~N 个标签，完全自由输入
- 输入时支持**回车确认**、**逗号分隔**自动拆分
- 重复标签自动去重
- 标签云按使用次数排序，点击即筛选

### 4 套数据流主题

| 主题名 | 主色调 | 背景 |
|--------|--------|------|
| 经典黑客绿（默认） | `#00ff41` | 深黑 `#0a0a0a` |
| 赛博蓝 | `#00d4ff` | 深蓝黑 `#070f1a` |
| 暗紫 | `#c77dff` | 深紫黑 `#110819` |
| 琥珀橙 | `#ffb703` | 深橙黑 `#1a1208` |

> 每套主题背景均叠有对应色调的数字雨动画 + 半透明遮罩，确保文字清晰可读。

### 字体预设

1. 等宽字体（`Consolas / Monaco / 'Courier New'`，默认黑客风格）
2. 无衬线黑体（`'Microsoft YaHei' / 'PingFang SC' / sans-serif`）
3. 衬线宋体（`'SimSun' / 'Songti SC' / serif`）
4. 楷体（`'KaiTi' / 'STKaiti' / serif`）

### 卡片展示与动画

**响应式瀑布流布局**

| 屏宽 | 列数 |
|------|------|
| ≥1400px | 4 列 |
| ≥1024px | 3 列 |
| ≥640px | 2 列 |
| <640px | 1 列 |

也可在顶栏手动切换列数。

**动画效果**

- 卡片少时（< 一屏）：缓慢上下浮动 4~8px，周期 3~5 秒
- 卡片多时：纵向自动循环滚动，悬停暂停，支持手动暂停 / 继续
- 新卡片入场：淡入 + 上移
- 删除卡片：缩小淡出，其余卡片平滑补位
- Hover：轻微上浮 + 主题色外发光
- 数字雨背景：Canvas 实现，经典黑客雨样式（亮白头部 + 指数衰减尾迹）

### 本地导入 / 导出

| 功能 | 说明 |
|------|------|
| 导出 | 下载 `灵感备份_YYYYMMDD_HHMMSS.json`，含全部卡片与配置 |
| 导入 | 选择 `.json` 文件后预览，确认执行 |
| 冲突处理 | ① 覆盖模式（清空现有，替换为导入数据）；② 合并模式（按 ID 去重追加） |

### 首次启动引导

首次打开展示 5 步蒙层引导：欢迎 → 新建灵感 → 标签管理 → 个性化外观 → 数据备份。
引导结束后写入 `hasShownGuide=true`，顶栏「❓」按钮可重新查看。

## 数据结构

### 单条灵感（Card）

```json
{
  "id": "uuid_xxxxxxxxxxxx",
  "title": "灵感标题（可选，可空）",
  "content": "灵感正文内容",
  "tags": ["标签1", "标签2"],
  "cardColor": "theme_default",
  "createdAt": 1723785600000,
  "updatedAt": 1723785600000
}
```

### 全局配置（Config）

```json
{
  "theme": "green",
  "fontFamily": "mono",
  "sortBy": "updatedAt_desc",
  "cols": "auto",
  "hasShownGuide": true
}
```

### 导出 JSON 结构

```json
{
  "version": "1.0",
  "exportedAt": 1723785600000,
  "config": { },
  "cards": [ ]
}
```

- **整体风格**：黑客帝国 / 数据流 / 暗色控制台 / 荧光发光边框 / 等宽字体默认
